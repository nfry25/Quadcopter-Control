# Simulink model and Subsystem design of 6 DOF Rigid-Body Quadcopter For Trajectory Mapping
##### NED Earth frame, fixed-body inertial frame, linearized at hover. Optimized PD control parameters developed for feedback loops. Airframe is based on a fixed-mass model using Euler angles. Model takes into account motor mixing algorithm to address under-actuation of the four rotor system inputs being used to produce the six DOF.
##### The controlled system, as shown by the outputs from the model runtime, shows nearly perfect control of the system when a trajectory input, which had been altered from the original hover-state to a coordinate-- with constants representing command inputs for yaw, X, Y, and -Z -- to verify the controllability of model.
